---
title: Make videos
description: Turn a description, or a starting picture, into a short clip.
---

**Videos** turns a description into a short clip. Some video models can also animate a picture you give them.

:::caution[Video is the most demanding task]
Video models are large and slow. Expect a few minutes per clip even on a good graphics card, and check the rating in
**Get models** carefully. When a model only fits by spilling into system memory, it can use most of your computer's
memory while it works.
:::

## Make a clip

1. Install a video model from **Get models → Videos**.
2. Open **Videos**, describe the scene and the motion, and press **Create**.

For a model that animates a picture, add one with **Start from a picture**. Models that *need* a picture show **Add
starting picture** instead, and the description becomes optional: *"Describe how the picture should move"*.

## Options

| Option | What it does |
| --- | --- |
| **Shape** | **Square**, **Wide** or **Tall**. |
| **Length** | **2 seconds** (fastest to make), **4 seconds** or **6 seconds** (takes the longest). |
| **Quality** | **Quick**, **Balanced** or **Best**. |

Under **More settings**: **Things to avoid** (for example *blurry, flickering, text*) and **Seed** (the same seed and
description give the same video).

Finished clips appear above the prompt bar and in the **Gallery**, and can be saved as MP4 files.
